# 五十音・墨影連連看

一款完全離線、以原生 HTML／CSS／JavaScript 製作的五十音連連看遊戲。玩家在 5 分鐘內，依傳統連連看規則把 15 張平假名牌與 15 張赫本式羅馬拼音牌配對消除。

## 如何開啟

直接雙擊專案根目錄的 index.html，或把它拖進現代瀏覽器即可遊玩。不需要啟動伺服器、不需要安裝套件，遊戲執行時也不會呼叫外部 API。

## 支援平台

- Windows、macOS、Linux 的現代桌面瀏覽器
- iOS／iPadOS Safari
- Android Chrome
- 響應式版面最低支援 320px 寬度；手機會隱藏不必要的側邊裝飾，維持棋盤與觸控按鈕清楚

## 主要玩法

依序選擇一張平假名牌與正確的羅馬拼音牌。兩張牌必須：

1. 種類不同（一張平假名、一張羅馬拼音）
2. 配對 ID 相同
3. 可以在 6×6 棋盤內用水平或垂直路徑連接
4. 最多轉彎兩次，且不能穿過其他尚未消除的牌

本作只包含あ行、か行、さ行；「し」固定配對 shi。棋盤共有 30 張牌與 6 個空白通道。

## 主要功能

- 5 分鐘倒數，按下「開始修行」後才計時
- BFS 路徑搜尋；狀態同時記錄位置、方向、轉彎數與完整路徑
- 逆向放置式可解棋盤生成、完整解序驗證、最大重試次數與相鄰牌備援配置
- 每次消除後自動偵測死局；死局會免費重新布陣並重設 Combo
- 劍氣折線、爆炸消除、朱紅成功印章動畫
- 100 基礎分、Combo 加成、完成時間獎勵
- 合法提示（扣 50 分）與僅重排剩餘牌的可解洗牌（扣 100 分）
- 自訂重新開始確認視窗，沒有使用原生 confirm()
- 成功／失敗結算、最高 Combo、錯誤次數與配對進度統計
- Web Speech API 日語發音
- 鍵盤焦點樣式、ARIA 棋盤資訊與減少動態偏好支援

## 圖片資產

assets/images/ 內的 13 張正式圖片全部使用 Codex 內建繪圖模型生成，並以 style-guide-map.webp 作為整套作品的筆觸、材質與配色基準。透明 PNG 使用純色去背底生成後，在本機移除背景並驗證 Alpha。

已生成：

- 風格基準圖、主背景、卷軸面板、標題牌
- あ行／か行／さ行主題圖
- 浮世繪浪紋、左右不同構圖的山景
- 武俠人物剪影、成功印章、完成畫面背景

牌卡文字仍由 HTML 渲染；卷軸美術只作為牌面材質，以確保假名與羅馬拼音在小螢幕上也清楚。

完整提示詞、尺寸、格式、透明背景與生成狀態記錄在 assets/generated-assets.json。標題牌已目視逐字確認為「五十音・墨影連連看」。

## 重新生成圖片

專案提供 scripts/generate_images.py 作為 API 備援重生工具。內建圖像工具可用時，仍建議優先以內建工具產圖。

使用腳本前：

1. 安裝 openai 與 Pillow
2. 在本機設定 OPENAI_API_KEY
3. 可選擇設定 OPENAI_IMAGE_MODEL；未設定時使用腳本撰寫當下的官方圖像模型 gpt-image-2
4. 在專案根目錄執行 python scripts/generate_images.py

腳本不會把 API 金鑰寫入檔案或輸出到日誌。透明圖會自動使用去背色並輸出 RGBA PNG。重新生成標題牌後，仍必須人工逐字檢查中文字。

## 圖片生成失敗時的備援

目前正式版本沒有圖片生成失敗，fallbackAssets 為空。若日後重新生成失敗：

- 保留現有圖片即可繼續離線遊玩
- index.html 內已使用和紙色、手繪邊框、漸層與 SVG 劍氣作為載入失敗時的視覺備援
- 圖片缺失不會影響棋盤、配對、計分、倒數與結算邏輯

## Web Speech API 限制

發音使用瀏覽器內建 speechSynthesis，語言設定為 ja-JP、速度 0.8、音高 1.0。實際聲音取決於作業系統是否安裝日語語音：

- 部分行動瀏覽器要求先有使用者點擊，之後才允許播放聲音
- 某些瀏覽器在直接以 file:// 開啟時，可能限制或延遲語音
- 沒有日語語音時，瀏覽器可能改用預設聲音
- 不支援時會顯示非阻斷提示，遊戲其他功能不受影響

## 離線與資料

遊戲沒有追蹤、登入、廣告或網路請求。所有程式都在 index.html 內，圖片全部使用相對路徑。
