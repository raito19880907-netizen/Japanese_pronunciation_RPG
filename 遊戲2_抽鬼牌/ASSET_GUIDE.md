# 美術素材製作與替換指南

本遊戲的最終美術由內建繪圖模型逐項生成，再用本機影像工具縮圖、轉為 WebP；配對印章與名牌先產生可去背底色，再做透明化處理。所有後續素材都把 `style-anchor.webp` 當作嚴格視覺參考，以維持同一位畫師般的線條、紙材與色盤。

## 共用風格提示

> 手繪彩色鉛筆＋淡水彩＋水墨線條，細密石墨筆觸，泛黃纖維和紙；武俠江湖道場融合浮世繪構圖。暖赭宣紙、炭黑、低彩度靛青、松綠與朱紅印記，僅少量古金。溫暖燈籠光、沉著而有冒險感。禁止寫實攝影、亮面 3D、扁平 icon、emoji、浮水印與現代物件。

## 生成順序與提示詞組

1. `style-anchor.webp`
   - 江湖道場內的四人和風低桌，遠山、松枝、瀑布、屏風、卷軸、墨雲與朱印；橫式完整場景，中央清楚、無人物與文字。
2. `bg-table.webp`
   - 參照 anchor，俯視方形木桌，中央大面積宣紙牌面；四邊為座位 UI 留空，裝飾集中角落，16:9，無牌與文字。
3. `title-sign.webp`
   - 參照 anchor，深色木框、靛青織錦卷軸頭、朱紅繩結、松枝與墨雲；寬橫式、中心留白。實際標題以 HTML 疊入「五十音抽鬼牌」，避免生成字誤與縮放模糊。
4. `nameplate-*.webp`
   - 參照 anchor，小型橫式卷軸名牌、靛青漆木與朱紅繩結、透明外圍。四個檔案共用同一材質，名稱由 HTML 精確疊字。
5. `card-back.webp`
   - 參照 anchor，2:3 直式，靛青底、對稱松針、浮世繪波浪、交叉毛筆與中央朱紅紋章；無字。
6. `card-frame-kana.webp`
   - 參照 anchor，2:3 正視圖，象牙和紙、炭黑雙框、朱紅筆觸、梅花角飾；中央大留白，假名由 HTML 疊字。
7. `card-frame-romaji.webp`
   - 與假名牌同系列，以靛青浪紋區分；中央大留白，羅馬拼音由 HTML 疊字。
8. `card-joker-1.webp`
   - 裂紋白色般若妖面、紫藍鬼火、墨雲、破損符札與朱印；家庭友善、無血腥、無字。
9. `card-joker-2.webp`
   - 從破損山水卷軸竄出的墨龍、青藍鬼火與朱印；和第一張同系列但輪廓明顯不同。
10. `stamp-success.webp`
    - 朱砂圓印，兩張配對牌由一筆連起，乾刷與手刻缺口；先在純 `#00ff00` 背景生成，再去背成透明 WebP。
11. `panel-rules.webp`
    - 4:5 直式規則卷軸，靛青錦緞軸、朱紅繩結、角落小牌與墨雲，中央 75% 留白供 HTML 規則文字。
12. `result-win.webp`
    - 道場露台日出、飛起的空白配對牌、朱紅緞帶與山霧；下方留結果文字區，莊重慶賀。
13. `result-lose.webp`
    - 月夜道場、中央受詛咒牌、藍紫鬼火與般若墨影；下方留結果文字區，詭譎但不血腥。

| `bg-table.webp` | 16:9 | 實際遊戲桌背景 |
| `title-sign.webp` | 2:1 | 開始標題卷軸、確認視窗材質 |
| `nameplate-*.webp` | 約 3:1、透明 | 四個座位名稱與張數 |
| `card-back.webp` | 2:3 | 所有電腦牌背與保密抽牌動畫 |
| `card-frame-kana.webp` | 2:3 | 假名牌 HTML 疊字底圖 |
| `card-frame-romaji.webp` | 2:3 | 羅馬拼音牌 HTML 疊字底圖 |
| `card-joker-1.webp` | 2:3 | 妖面鬼牌正面 |
| `card-joker-2.webp` | 2:3 | 墨龍鬼牌正面 |

## 替換方式

保留檔名與大致比例，直接替換同名 WebP 即可。牌面學習文字與標題、座位名稱都在 HTML/JavaScript 中疊字，不要把文字烘焙進卡框；這能保持手機可讀性，也方便日後擴充濁音、拗音或其他行。
