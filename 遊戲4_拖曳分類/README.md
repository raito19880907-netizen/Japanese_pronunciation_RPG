# 平假名 46 音配對遊戲｜言靈武林

這是一個不依賴外部框架的單頁網頁遊戲，使用原生 HTML、CSS 與 JavaScript 製作。

## 執行方式

1. 直接雙擊 `index.html`，即可在現代瀏覽器開啟。
2. 若瀏覽器限制本機語音或儲存功能，可在此資料夾啟動簡易本機伺服器，再開啟顯示的網址：

   ```powershell
   python -m http.server 8000
   ```

   然後前往 `http://localhost:8000/`。

## 操作

- 電腦預設為拖曳模式：把假名卡片拖到正確的五十音行。
- 觸控裝置預設為點選模式：先點假名，再點分類。
- 可在「設定」或關卡工具列切換操作方式、音效與日語發音。
- 完成全部題目且正確率高於 80% 才算通關，並解鎖下一關。
- 進度與設定儲存在瀏覽器 `localStorage`；若不可用，遊戲仍可正常進行。

## 檔案結構

```text
遊戲4_拖曳分類/
├─ index.html
├─ README.md
└─ assets/
   ├─ images/   # 世界地圖、六張關卡圖、標題牌、角色與十一枚紋章
   └─ audio/    # 本版留空；音效由 Web Audio API 即時產生
```

本遊戲不含背景音樂，也不需要網路連線或外部 API。
